# Demo Script

## 1. Problem Introduction

**Speaker:**

"FairScreen is an AI-assisted prototype designed to audit whether an AI candidate-screening system produces different outcomes when selected candidate attributes are changed while job-relevant qualifications remain constant.

The purpose of the prototype is to identify observed differences in model behaviour and provide evidence for further human review."

---

## 2. Introduce the Technology

**Speaker:**

"The prototype was developed using Python in Visual Studio Code. Google Gemini API is used as the generative AI component. The application accepts candidate information, performs the screening analysis, and provides a structured result."

**Technology used:**

* Python
* Visual Studio Code
* Google Gemini API
* [Streamlit, if actually used]

Open the FairScreen Python application.

Show the candidate input fields or input section.

## 4. Run the Original Candidate

Enter the demonstration candidate.

Run the screening process.

Show the original candidate's result.

**Speaker:**

"This is the result produced for the original candidate. The job-relevant qualifications are recorded and the selected candidate attribute is also part of the test condition."

## 5. Generate the Counterfactual Candidate

Create a counterfactual version of the same candidate.

Change **only the selected candidate attribute** being tested.

Keep the job-relevant qualifications unchanged.

**Speaker:**

"The purpose of this controlled comparison is to change one selected attribute while keeping the job-relevant qualifications constant."

---

## 6. Run the Counterfactual Screening

Run the screening process for the counterfactual candidate.

Show the generated result.

Compare it with the original candidate's result.

---

## 7. Compare the Results

Show the original and counterfactual results.

**Speaker:**

"We now compare the two outputs.

If the screening decision changed, we record this as an observed decision change.

If the decision remained the same, we record that the tested pair produced consistent outcomes.

An observed difference does not by itself establish the underlying cause of the difference."

---

## 8. Run the Automated Audit

Run the automated counterfactual evaluation implemented in the prototype.

Show the actual metrics generated by the system.

Display:

* Total counterfactual pairs tested: 30
* Changed decisions: 4 
* Decision Flip Rate: 13.33%

**Speaker:**

"This automated audit applies the same comparison procedure across the tested candidate pairs. These are the observed results for our evaluation dataset."

---

"We first tested an initial prompt and then refined it based on the issues observed during testing.

The changes and their effects are documented using the actual testing results."
